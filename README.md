# raffaelecamanzo/homebrew-tap

Homebrew formulas for tools by [@raffaelecamanzo](https://github.com/raffaelecamanzo).

## Install

```bash
brew install raffaelecamanzo/tap/<formula>
```

Or tap once, then install by short name:

```bash
brew tap raffaelecamanzo/tap
brew install <formula>
```

## Formulas

| Formula | Description |
|---|---|
| [`logos`](https://github.com/raffaelecamanzo/logos) | Graph-based code navigation and quality enforcement for AI agents |

## How formulas get here

Each formula is generated and pushed by its project's release pipeline
([cargo-dist](https://github.com/axodotdev/cargo-dist)) when a version is tagged.
Please don't edit them by hand: the next release overwrites the file. Report
problems in the project's own repository.
